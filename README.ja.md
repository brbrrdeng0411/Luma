# Luma

**言語:** [한국어](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

Luma は **Windows 向けのローカル画像ライブラリアプリ**です。指定したフォルダー内の画像を閲覧し、タグで整理し、タグ検索や絞り込みで目的の画像を探すために作られています。booru サイトのようなタグによる探し方を、個人のローカルライブラリに取り入れています。

## 主な機能

- 指定したフォルダーとサブフォルダー内の画像を閲覧
- PNG、JPG/JPEG、WebP、GIF、BMP に対応
- 画像ごとに複数のタグを付与し、既存のタグを再利用
- 複数タグによる検索と絞り込み
- 画像ビューアーとサムネイル一覧を連動
- タグ別フォルダーへ元画像を移動・複製せずにライブラリを構成

## ダウンロードと起動

**Releases** から **Luma v1.3.8** の Windows 向け配布ファイルを入手してください。必要に応じて展開し、同梱の実行ファイルを起動してください。

## プロジェクトの方針

Luma は複雑な管理画面よりも、**画像を快適に鑑賞し、タグですばやく探すこと**を重視しています。

## 今後の更新予定

- ライブラリのタグを画像の EXIF メタデータに統合
