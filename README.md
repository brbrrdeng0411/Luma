# Luma

**언어:** [한국어](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) 동명의 다른 프로젝트와 이름이 겹치는 것은 우연의 일치이며, Luma는 완전한 비영리 프로젝트입니다.

Luma는 **Windows용 로컬 이미지 라이브러리**입니다. 선택한 폴더의 이미지를 감상하면서 태그로 정리하고, 필요한 이미지를 검색·필터링할 수 있도록 만든 프로그램입니다. booru 스타일의 태그 탐색 방식을 개인 로컬 라이브러리에 적용했습니다.

### 주의
100% 취미로 만든 앱입니다. 버그와 엉망진창으로 만든 기능이 가득합니다. 언제 업데이트할지는 제작자도 모릅니다.

## 핵심 기능

- 선택한 폴더와 하위 폴더의 이미지를 라이브러리에서 탐색
- PNG, JPG/JPEG, WebP, GIF, BMP 이미지 지원
- 이미지별 복수 태그 등록 및 기존 태그 재사용
- 여러 태그를 이용한 이미지 검색·필터링
- 이미지 뷰어와 썸네일 목록을 연결한 감상 흐름
- 라이브러리를 만들기 위해 이미지 파일을 별도 태그 폴더로 이동하거나 복제하지 않는 방식

## 프로젝트 소개

Luma의 목표는 사진을 관리하는 복잡한 화면보다 **이미지를 감상하고 태그로 빠르게 찾아보는 작업**에 집중하는 것입니다.
