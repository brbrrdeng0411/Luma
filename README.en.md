# Luma

**Languages:** [한국어](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md)

Luma is a **local image library for Windows**. It is designed for browsing pictures in a folder, organizing them with tags, and finding them through tag-based search and filtering. It brings booru-style tag navigation to a personal, local collection.

## Core features

- Browse images from a selected folder and its subfolders
- Support for PNG, JPG/JPEG, WebP, GIF, and BMP images
- Assign multiple tags to an image and reuse existing tags
- Search and filter images using multiple tags
- Browse images with a connected viewer and thumbnail list
- Organize a library without moving or duplicating images into tag-specific folders

## Download and run

Open the **Releases** section and download the Windows distribution for **Luma v1.0.0**. Extract the archive if necessary, then run the included application.

## Project focus

Luma is built around **viewing images and finding them through tags**, rather than turning a personal collection into a complicated management interface.
