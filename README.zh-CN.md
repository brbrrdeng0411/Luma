# Luma

**语言：** [한국어](README.md) · [English](README.en.md) · [日本語](README.ja.md) · [简体中文](README.zh-CN.md) 如与其他项目同名，纯属巧合；Luma 是一个完全非营利的项目。

Luma 是一款**适用于 Windows 的本地图片资料库应用**。您可以浏览指定文件夹中的图片，使用标签进行整理，并通过标签搜索和筛选找到需要的图片。它将 booru 风格的标签浏览方式应用于个人本地图库。

## 主要功能

- 浏览所选文件夹及其子文件夹中的图片
- 支持 PNG、JPG/JPEG、WebP、GIF 和 BMP 图片
- 为每张图片添加多个标签，并重复使用已有标签
- 使用多个标签搜索和筛选图片
- 图片查看器与缩略图列表联动
- 无需将原图移动或复制到按标签分类的文件夹中

## 下载与运行

在 **Releases** 页面下载 **Luma v1.3.8** 的 Windows 发布文件。根据发布文件的格式解压，然后运行其中的程序即可。

## 项目理念

Luma 专注于**舒适地浏览图片，并通过标签快速查找内容**，而不是提供复杂的管理界面。

## 更新计划

- 通过 CSV 批量导入标签库
- 将标签库中的标签合并到图片的 EXIF 元数据中
